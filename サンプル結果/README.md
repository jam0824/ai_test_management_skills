# サンプル結果

このプラグインのスキルで、実際にテストを最初から最後まで回すと、どんな成果物ができるかの見本です。

## sample_test（バグ仕込み前状態）

Web版の老後資金シミュレーター(HTML 1枚)を、`test-manager` のスキルで、要求仕様整理からテストレポートまで通しでテストした結果です。テスト対象は、スキルの検出力を試すために不具合を仕込む前の版です(見つかった不具合は、意図して入れたものではなく、もともとのアプリにあった動きです)。

### まず開くもの

**`sample_test（バグ仕込み前状態）/テスト成果物/テストレポート.html`** をブラウザで開いてください。最新のテストレポートに飛びます。

ブラウザによってはファイルを直接開くとリンクがうまく動かないことがあります。そのときは、ローカルだけで配信して開いてください。

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory "サンプル結果/sample_test（バグ仕込み前状態）/テスト成果物"
# http://127.0.0.1:8000/テストレポート.html を開く
```

工程ごとの結果は、各工程のフォルダの HTML(`02_リスク分析/リスク分析.html` など)か、`テスト成果物/結果まとめ/目次.html` から開けます。

### 中身

```
sample_test（バグ仕込み前状態）/
├─ retirement_simulator.html   テスト対象
├─ README.md                   テストベース(テスト対象の仕様書)
├─ e2e/                        E2E自動テストスクリプト(Playwright)
└─ テスト成果物/
   ├─ テストレポート.html       最新のテストレポートへの入口
   ├─ 質問表.md / 進行状況.md / 戻し記録.md
   ├─ 01_要求仕様/ … 07_E2E自動テストスクリプト/   工程ごとの成果物(Markdown)とページ(HTML)
   ├─ 08_テスト実行/
   │   ├─ RUN-20261123-091035/   テスト実行(テスト結果・証跡・探索的テストのセッションシート)
   │   ├─ RUN-20261123-145445/   回答待ちの質問の実機確認(observe-actual-behavior)
   │   └─ 欠陥レポート.md
   ├─ 09_テストレポート/<日時>/  テストレポート(作った時点の成果物の写し snapshot を含む)
   └─ 結果まとめ/              目次・ID索引・全工程のページ
```

### 見本として整えたこと

- Playwright のトレース(`*trace.zip`。1つで数十〜100MB)と、テストのたびに出る生の出力(`e2e/test-results/`)は、大きすぎるので入れていません。証跡のうちトレースへのリンクは切れますが、スクリーンショットと動画は見られます。
- 回答待ちの質問の実機確認は、テスト活動のあとで足しました。そのため、テストレポートは同じ日時のまま、今の成果物で作り直しています(レポートの作成日時の表示は、最初に作ったときのままです)。
- HTML のページは、このリポジトリの今のスクリプトで作り直しています。
