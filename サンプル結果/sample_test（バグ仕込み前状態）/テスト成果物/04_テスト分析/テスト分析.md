# テスト分析

入力: `03_テスト計画/テスト計画.md`(TA-001〜TA-019)、`01_要求仕様/要求.md`(REQ-001〜REQ-013)、`01_要求仕様/仕様.md`(SPEC-001〜SPEC-064)、`02_リスク分析/リスク分析.md`(RISK-001〜RISK-045)、`質問表.md`(Q-001〜Q-019 は未回答)。

- テストオラクルは仕様(と質問の回答)から決め、テスト対象の画面の実装から写さない(テスト計画の制約のとおり)。たとえば、画面の実装にある取り崩しの20%の税金は資料に無いので、期待する結果に使わない。
- 質問の回答を待つのは、テストベースから期待する結果や合否の基準を決められない部分だけにした。決められる部分(性質で判定できる部分、境目の年の前後の年など)は、`備考` に「回答を待たずに判定できる」と書いた。回答で基準が変わるかもしれないものは「Q-xxx の回答で基準が変わりうる」と書いた。
- 優先順位は、紐づくリスクのうち最も高いリスクの区分(高 / 中 / 低)にそろえた。そうしていないものは `備考` に理由を書いた。
