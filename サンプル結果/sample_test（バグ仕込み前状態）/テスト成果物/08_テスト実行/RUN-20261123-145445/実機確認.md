## 途中で気づいた動き

どう答えが来ても問題になりそうな動きとして、次のものを見た。どれも既存の欠陥レポートに同じものがある。

- 取り崩しで投資の残高がマイナスになる(Q-010 の30歳6月、Q-011、Q-016 の(1))。→ BUG-001
- マイナスの投資の残高に利回りがかかる(Q-011 の「¥-20,000 → ¥-20,800」)。→ BUG-003
- 取り崩しの額と投資利息の行に円未満の小数が出る(Q-021 の「¥61,537.5」、Q-001 の証跡の「¥21,330,037.684」)。→ BUG-009
- 資金が尽きても知らせが無い(Q-011)。→ BUG-011
