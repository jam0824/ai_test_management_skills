## 課題
- ほかのセッションの候補と重なるもの: 「万」などの文字が欄から捨てられる振る舞いは、候補-SES-003-2(欄に文字が見えているのに空として扱われる)と同じ数値の入力欄の仕組みから来ている見込み(現れ方は違う)。円未満の小数を不正な値のまま使うことは SES-003 テストメモ16 と重なる
- 内蔵ブラウザで、自分のタブが前面に無いときは画面が描かれず、クリック・キー入力・スクリーンショットができない。このセッションでは、画面が描かれていたとき(テストメモ1・8・19・22〜25・28・30)だけクリックとキーやスクリーンショットを使い、ほかは値の入力と「開始」を JavaScript にした。そのため、JavaScript で入れた値は、キーで打ったときの「文字が捨てられる」動きを通っていない
- テストメモ23 で、内蔵ブラウザの中で Ctrl+C・Ctrl+V を試したが、数字だけの文字でも欄に貼れず、貼り付けの振る舞いは確かめられなかった(Ctrl+C は利用者のPCのクリップボードに「¥188,125」「188」を書いた可能性がある)
- テストメモ19 の全角の打ち方は、全角の文字をそのまま送ったもので、日本語入力(IME)で変換して確定する操作は試していない
- Q-020 (1) が未回答のため、候補-SES-010-1・2 は回答待ちのまま報告する。Q-004(現役時生活費の初期値 15.6万円と 155,600 の違い)も、README の万円の数字を円に直す利用者にとって同じ領域の問題
