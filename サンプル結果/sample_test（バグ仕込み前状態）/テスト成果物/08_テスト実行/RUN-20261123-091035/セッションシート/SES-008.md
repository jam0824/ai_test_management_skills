## 課題
- ほかのセッションの候補と重なるもの(セッションシートを読んで確かめた。欠陥レポートにまとめるときに重ねないでほしい): 候補-SES-008-1・3 は 候補-SES-001-2・候補-SES-005-1・候補-SES-005-2・候補-SES-013-1 と、候補-SES-008-7 は 候補-SES-001-3・候補-SES-005-3・候補-SES-014-1 と、候補-SES-008-5 は 候補-SES-005-4・候補-SES-012-3 と、同じ振る舞いの見込み。候補-SES-008-4(`¥-0`)は 候補-SES-002-2 にも `¥-0` が出てくる
- 内蔵ブラウザで、自分のタブが前面に無いと画面が描かれず、クリック・キー入力・スクリーンショットが失敗する(テストメモ3以降。ほかのエージェントのタブが前面にある)。テスト環境.md の「探索的テストの環境」は、欄をトリプルクリックしてキーを打つ入れ方にしているが、エージェントが同時に動くときはこの入れ方ができない。今回は form_input と JavaScript(入力欄の value を変える、`runBtn` の click)で入れたので、キーを1つずつ打ったときの振る舞い(文字が入らないなど)は見ていない。スクリーンショットの代わりに、結果の欄の文字を抜き出して証跡にした
- 取り崩しの処理と給与変更の読み取りは、振る舞いの原因を確かめるために、配信された画面のソースを curl で読んだ(テスト対象のファイルは変えていない)
- Q-011(資金が尽きたときの計算と表示)の回答が無いため、候補-SES-008-2 の重要度と合否の基準が決まらない。候補-SES-008-1・3 は「投資は0円以上」の性質で判定した
- 候補-SES-008-5(給与変更の年収0円)は、E2E自動テストの HTC-061 の0円のケースと同じ不具合の見込み。欠陥レポートにまとめるときに重ならないようにしてほしい
