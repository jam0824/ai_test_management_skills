# テストデータ

テスト設計のテストデータ要件から作った。ファイルは `テストデータ/` にあり、どれも JSON(UTF-8)。個人情報や本番のデータは使っていない(金額と年齢は、テストの目的に合わせて決めた架空の値)。

- 各ファイルの `ローレベルテストケース` の下に、ローレベルテストケースのIDごとの 条件(入力欄の id と値)・給与変更(年齢, 年収)・乱数・操作・比較用の実行・期待値 がある。値はローレベルテストケースの表と同じ。
- 書いていない入力欄は、画面を開いたときの値(初期値)のまま使う。

| ID | 内容 | ファイル |
|---|---|---|
| TD-001 | 入力欄の id と名前、README の初期値(13項目)、略記(取り崩しなし・利息なし・項目を別々の額に)の値 | テストデータ/設定項目.json |
| TD-002 | 乱数の差し替え方(支出なし、1か月だけ起こす、シードつき疑似乱数、両端の並び) | テストデータ/乱数.json |
| TD-003 | 「開始」と開始し直し、結果の月の並びを見る条件 | テストデータ/実行と結果の並び.json |
| TD-004 | ありえない値の代表(空欄、負の金額、100%を超える投資率、整数でない年齢、数字でない文字) | テストデータ/ありえない値.json |
| TD-005 | README の使用例ケース1〜4の条件と、年収の比較用の実行 | テストデータ/使用例.json |
| TD-006 | 期間ごとの収入と生活費を別々の額にした設定と、開始年齢・退職年齢・年金開始年齢の組 | テストデータ/期間.json |
| TD-007 | 手取りを見る基本年収(0円、479,999〜480,001円、0円〜12,000,000円を250,000円ずつ) | テストデータ/手取り.json |
| TD-008 | 投資率(0%・1%・20%・99%・100%)と、利回りを見る開始時投資残高・利回り | テストデータ/投資と利回り.json |
| TD-009 | 取り崩しの境目(開始時貯金・開始時投資残高の境界値)、取り崩しが起き資金は尽きない設定 | テストデータ/取り崩しと総資産.json |
| TD-010 | 給与変更の設定の組(1つ・2つ・3つ、順の違い、S−1・R・R+1、年収0円・1円)と、年収の比較用の実行 | テストデータ/給与変更.json |
| TD-011 | 突発的な支出の発生率(0%・0.1%・0.5%・1%・30%・99.9%・100%、種類を見る50%)と、シード | テストデータ/突発的な支出.json |
| TD-012 | 14項目すべてに入れる値と給与変更の操作(通信とオフラインのテスト用。突発的な支出・取り崩し・利息がすべて結果に出る設定) | テストデータ/通信とオフライン.json |
| TD-013 | ソースを確かめるチェックリストの4項目と検索語、テスト対象の SHA-256 | テストデータ/ソースのチェックリスト.json |
| TD-014 | 探索的テストで使える値の手がかり(テストチャーターごと) | テストデータ/探索的テスト.json |
| TD-015 | ブラウザの互換性のテストで流すローレベルテストケースの一覧 | テストデータ/ブラウザ.json |

テスト設計のテストデータ要件のうち、次の2つは回答待ちのハイレベルテストケースだけが使うので、作っていない(`未実装.md`)。

- 所得税の区分の境目と、課税される額が0になる境目の年収(HTC-033、HTC-035。Q-005・Q-006 の回答待ち)
- すべての種類の突発的な支出が起きる乱数の並び(HTC-072。Q-014 の回答待ち)
