## テストチャーター

CH-006: 取り崩しの計算を、取り崩しが長く続く条件、資金が尽きる条件、尽きた後に年金などの収入が生活費を上回る条件で探索し、資産の推移のおかしなところを見つける。

- 対象の領域: 投資の取り崩しと結果の残高(テスト条件 COND-043。性質は COND-038、COND-041)
- 気にするリスク: 投資の残高が0未満になる。取り崩した後も投資の残高が残っているのに、現金が0未満のまま
- 資金が尽きた後の期待する結果は Q-011 の回答待ち。取り崩す額と税金は Q-010 の回答待ちなので、判定には使わず記録だけにした

  2. 給与(年収)を 0、開始時貯金を 0、開始時投資残高を 160000、投資率を 0、利回りを 0、イベント発生率を 0 にする(ほかは初期値。現役時生活費 155600)
