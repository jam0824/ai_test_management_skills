SES-017 (CH-003) 設定項目の文字と整数でない年齢の観察記録
テスト対象: http://localhost:8000/retirement_simulator.html / Claude の内蔵ブラウザ(Chromium系) / 自分のタブ tab-7
条件: イベント発生率 0、ほかは初期値(とくに書かないかぎり)。値はキーボードで打った。
「欄の値」は JavaScript で読んだ value(!bad は badInput、!step は stepMismatch)。
基準(初期値・イベント発生率0): 給与420か月・年金432か月、100歳12月の総資産 ¥35,594,188

1. 年齢の欄に小数点のつもりの記号
 退職年齢 "60,5"            → 欄の値 605(正しい値)。給与852か月(100歳12月まで)、年金0か月。総資産 ¥157,676,511
 退職年齢 "60、5"(読点)      → 605
 退職年齢 "６０。５"(全角+句点) → 605
 年金開始年齢 "67,5"        → 675。給与420か月、65歳1月から「退職後収入: ¥0」432か月、年金0か月。総資産 ¥-65,097,685
 年金開始年齢 "65。5"(句点)  → 655。上と同じ結果(総資産 ¥-65,097,685)
 年金開始年齢 "65・5"(中黒)  → 655
 年金開始年齢 "６５．５"(全角の点) → 65.5(!step)
 開始年齢 "30,5"            → 305。結果の欄は空(0文字)
 退職年齢 "60,5" と年金開始年齢 "65。5" を同時に → 給与852か月、年金0か月、総資産 ¥157,676,511(画面: SES-017_01)

2. 金額の欄
 給与 "3.000.000"   → 欄の値 "3.000000"(正しい値の状態)。30歳1月「給与: ¥0 (投資: ¥0)」。総資産 ¥-34,921,271
 現役時生活費 "155.600" → 155.6(!step)。「生活費: ¥155.6」
 老後生活費 "228e00"  → 228(正しい値)。65歳1月「生活費: ¥228」。総資産 ¥190,881,196
 老後生活費 "22e000"  → 22
 老後生活費 "2e8000"  → 空(!bad)
 老後生活費 "２２８Ｅ００"(全角) → 22800(全角のＥだけ捨てられる)
 老後生活費 "228〇〇〇"(漢数字のゼロ) → 228
 老後生活費 "228OOO"(英字のO) → 228
 老後生活費 "228、000" → 228000
 老後生活費 "228000e" → 空(!bad)。欄には「228000e」と見える。65歳1月「生活費: ¥0」、総資産 ¥190,979,692(画面: SES-017_02)
   "228000e" の欄で上矢印 → 1

3. 年齢の欄の末尾の文字
 年金開始年齢 "65e" → 空(!bad)。"65-" → 空(!bad)。"65." → 65。"6 5" → 65
 退職年齢 60・年金開始年齢 "65e" → 60歳1月から年金(492か月)、退職後収入0か月。総資産 ¥623,414
 退職年齢 60・年金開始年齢 65    → 60歳1月から退職後収入60か月、65歳1月から年金432か月。総資産 ¥-23,616,744
 退職年齢 "60-5" "60+5" → 空(!bad)。"1/2" → 12

4. 利回り
 "4,5" → 45。退職年齢 605・老後生活費 "1e"(空)と同時に → 総資産 ¥287,347,803,297,517,920
 "0x4" → 04。"4E" → 空(!bad)、続けて "1" → "4E1" = 40%(利息の行「投資: ¥451,500 → ¥632,100」)

5. 誤りを順に直す流れ(退職年齢 "60,5"、利回り "4,5"、老後生活費 "1e")
 3つとも誤り         → 給与852か月、年金0か月、総資産 ¥287,347,803,297,517,920
 退職年齢を 65 に直す → 給与420か月、年金432か月、総資産 ¥287,347,261,863,696,350
 利回りを 4 に直す    → 総資産 ¥190,979,692(老後生活費の "1e" が 0 のまま)
 老後生活費を 228000 に直す → 総資産 ¥35,594,188。結果の欄の文字が基準と完全に一致

6. 整数でない年齢の境目
 退職年齢 60.0000001 → 61歳1月から退職後収入(給与372か月)。総資産 ¥-16,894,623
 退職年齢 59.9999999 → 60歳1月から(給与360か月)。総資産 ¥-23,616,744
 開始年齢 99.99      → 「99.99歳1月」〜「99.99歳12月」の12か月
 開始年齢 100.0000001 → 結果の欄は空
 開始年齢 30.1・30.3・30.7・30.15 → 840か月。年齢の表示に浮動小数点の誤差(小数4桁以上)は出なかった
 開始年齢 0.1 → 1200か月
 退職年齢 60.5・年金開始年齢 61・退職後収入 100000 → 給与372か月、退職後収入0か月、61歳1月から年金480か月(退職後収入の 100000 は一度も使われない)
