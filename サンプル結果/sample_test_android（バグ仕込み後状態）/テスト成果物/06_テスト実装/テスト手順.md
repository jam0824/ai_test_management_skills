# テスト手順

手動テストのローレベルテストケースの手順。コマンドは PowerShell か bash で、作業ディレクトリ `D:/codes/sample_test_android` で打つ。adb は必ず `adb -s emulator-5554` で端末を指定する(実機 46211JEKB11275 には触らない)。Git Bash で `/sdcard/...` のようなパスを渡すときは、前に `MSYS_NO_PATHCONV=1` を付ける(付けないと Windows のパスに変えられる)。

証跡は `テスト成果物/08_テスト実行/RUN-…/` に、手順の番号を付けた名前で残す(画像: `adb -s emulator-5554 exec-out screencap -p > <名前>.png`、部品の一覧: `adb -s emulator-5554 shell uiautomator dump /sdcard/d.xml` のあと `adb -s emulator-5554 pull /sdcard/d.xml <名前>.xml`)。

手順の前に、表示が標準(`テスト環境.md` の「標準の表示」)になっていることを確かめる。E2E自動テストの読み取り用の表示のまま行わない。

| ID | ローレベルテストケースID | 概要 | 依存 |
|---|---|---|---|
| PROC-001 | LTC-066 | dumpsys package で宣言された権限を見る | PROC-004 のあと(アプリが入っている) |
| PROC-002 | LTC-067 | 操作の前後でアプリの uid の通信量を比べる | PROC-004 のあと。PROC-003 と同時に行わない(機内モードだと通信が起きえないので確かめにならない) |
| PROC-003 | LTC-068 | 機内モードで起動・開始・給与変更設定・回転を行う | PROC-004 のあと。終わったら機内モードを戻す |
| PROC-004 | LTC-072 | アンインストールした状態からインストールして起動する | 最初に行う(ほかの手動テストとE2E自動テストの前) |
| PROC-005 | LTC-073 | 10桁以上の総資産の行を画像で見る | PROC-004 のあと |
| PROC-006 | LTC-074 | 大きなマイナスの金額の行を画像で見る | PROC-004 のあと |
| PROC-007 | LTC-075 | 横向きで入力・開始し、結果の行を画像で見る | PROC-004 のあと。終わったら縦向きに戻す |

## PROC-001

### 準備
1. アプリが入っていることを確かめる: `adb -s emulator-5554 shell pm list packages jp.sample.retirementsimulator` で `package:jp.sample.retirementsimulator` が出る。

### 操作と確認
1. `adb -s emulator-5554 shell dumpsys package jp.sample.retirementsimulator > PROC-001_dumpsys.txt` を打つ。
2. ファイルの `requested permissions:` の下の行(次の見出し `install permissions:` の前まで)を読む。
3. 確認: その中に `android.permission.INTERNET` が無い(TD-010 の 権限)。あれば Fail。
4. 確認のために、ファイル全体でも `android.permission.INTERNET` を探し、出た行があれば記録する。

### 後片付け
なし。

## PROC-002

### 準備
1. 機内モードでないことを確かめる: `adb -s emulator-5554 shell cmd connectivity airplane-mode` が `disabled`。
2. アプリの uid を調べる: `adb -s emulator-5554 shell dumpsys package jp.sample.retirementsimulator` の `uid=` の値(例: 10187)を控える。
3. アプリを止める: `adb -s emulator-5554 shell am force-stop jp.sample.retirementsimulator`。

### 操作と確認
1. 操作の前の通信量を取る: `adb -s emulator-5554 shell dumpsys netstats > PROC-002_before.txt`。`mAppUidStatsMap:` の下の表(`uid rxBytes rxPackets txBytes txPackets`)で、控えた uid の行を探し、rxBytes と txBytes を記録する(行が無ければ 0 とする)。
2. 起動する: `adb -s emulator-5554 shell am start -n jp.sample.retirementsimulator/.MainActivity`。
3. 「開始」を押す(画面を下へスクロールして「開始」をタップ)。結果が出るのを待つ。
4. 画面を上に戻し、「📈 給与変更設定を表示/非表示」を押す。枠が出なければもう1回押す。「➕ 給与変更を追加」を押し、年齢に 40、年収に 5000000 を入れ(TD-010)、その行の「削除」を押す。
5. 回転する: `adb -s emulator-5554 shell settings put system accelerometer_rotation 0`、`adb -s emulator-5554 shell settings put system user_rotation 1`、3秒待つ、`adb -s emulator-5554 shell settings put system user_rotation 0`。
6. 10秒待ってから、操作の後の通信量を取る: `adb -s emulator-5554 shell dumpsys netstats > PROC-002_after.txt`。手順1と同じく uid の行を読む。
7. 確認: 操作の後の rxBytes・txBytes が、操作の前の値と同じ(増えていない)。増えていれば Fail。

### 後片付け
1. `adb -s emulator-5554 shell settings put system accelerometer_rotation 1`(自動回転を元に戻す)。

## PROC-003

### 準備
1. 機内モードでないことを確かめ、アプリを起動し直す(`am force-stop` → `am start`)。
2. 比べる結果を取る: `eventProb` に 0 を入れて「開始」を押し、結果の行を最後まで読む(E2E自動テストの読み取りの道具を使ってよい。使うときは読み取り用の表示にし、読み終わったら標準の表示に戻す)。結果をファイルに残す。
3. 機内モードにする: `adb -s emulator-5554 shell cmd connectivity airplane-mode enable`。`adb -s emulator-5554 shell cmd connectivity airplane-mode` が `enabled` になったことを確かめる。

### 操作と確認
1. アプリを止めて起動する(`am force-stop` → `am start`)。確認: 落ちずに入力欄が出る。画像を残す。
2. `eventProb` に 0 を入れて「開始」を押し、結果の行を最後まで読む(準備2と同じやり方)。確認: 結果が準備2の結果と同じ(月の記録の数とすべての文字)。
3. 画面を上に戻し、給与変更の枠を出して「➕ 給与変更を追加」を押し、年齢 40・年収 5000000 を入れる。確認: 行が1件増え、値が出る。その行の「削除」を押す。確認: 行が無くなる。
4. `eventProb` が 0 のままであることを見てから、横向きにする(`settings put system accelerometer_rotation 0`、`settings put system user_rotation 1`)。確認: 落ちない。下へスクロールして `eventProb` の値が 0 のままであること、さらに下へスクロールして結果の行(`outputLine`)が残っていることを見る(回転の直後は画面の上のほうが出ていて、結果の行が画面の外にあることがある)。画像を残す。
5. 縦向きに戻す(`settings put system user_rotation 0`)。確認: 手順4と同じくスクロールして、入力と結果が残っていることを見る。

### 後片付け
1. 機内モードを戻す: `adb -s emulator-5554 shell cmd connectivity airplane-mode disable`。`disabled` を確かめる。
2. `adb -s emulator-5554 shell settings put system accelerometer_rotation 1`。

## PROC-004

### 準備
1. APK を作る: `./gradlew assembleDebug`(JAVA_HOME は Android Studio 付属の JDK)。`app/build/outputs/apk/debug/app-debug.apk` ができたことを確かめる。
2. アプリを消す: `adb -s emulator-5554 uninstall jp.sample.retirementsimulator`(入っていなければ失敗してよい)。`adb -s emulator-5554 shell pm list packages jp.sample.retirementsimulator` が何も出さないことを確かめる。
3. クラッシュのログを消す: `adb -s emulator-5554 logcat -b crash -c`。

### 操作と確認
1. `adb -s emulator-5554 install app/build/outputs/apk/debug/app-debug.apk` を打つ。確認: `Success` が出る。
2. `adb -s emulator-5554 shell am start -n jp.sample.retirementsimulator/.MainActivity` を打ち、3秒待つ。
3. 画像と部品の一覧を残す。確認: 入力欄(`startAge` など)が出ている。
4. 画面を下へスクロールする。確認: 「開始」(`runBtn`)が出る。
5. 確認: 「isn't responding」「has stopped」のダイアログが出ていない。`adb -s emulator-5554 logcat -d -b crash` にアプリの行が無い。

### 後片付け
なし(アプリは入れたままにする。ほかのテストで使う)。

## PROC-005

### 準備
1. アプリを止めて起動する。縦向きであることを確かめる。

### 操作と確認
1. `initialCash` に 1000000000、`eventProb` に 0 を入れる(TD-010 の 桁の多い金額 (1))。キーボードを閉じる。
2. 下へスクロールして「開始」を押す。
3. 結果の行が出たところで、総資産が10桁以上(¥1,000,000,000 以上)の行が見える位置で画像を残す。続けて下へ何回かスクロールし、総資産の桁が増えた行(11桁以上になる行があればその行)でも画像を残す。
4. 確認(人): 画像で、10桁以上の総資産の金額が最後の桁まで見え、切れておらず、ほかの文字と重なっていない。行が折り返されているときは、折り返しで数字が分かれていないかも見る。

### 後片付け
なし。

## PROC-006

### 準備
1. アプリを止めて起動する。縦向きであることを確かめる。

### 操作と確認
1. `startAge` に 55、`expenseRetired` に 1000000、`eventProb` に 0 を入れる(TD-010 の 桁の多い金額 (2))。キーボードを閉じる。
2. 下へスクロールして「開始」を押す。
3. 結果の最後の行まで速くスクロールする(`adb -s emulator-5554 shell input swipe 540 1900 540 300 100` を、画面が動かなくなるまで繰り返す)。
4. 最後の行あたりで画像を残す。
5. 確認(人): 画像で、マイナスの大きな金額(例: ¥-数億)が、符号から最後の桁まで見え、切れておらず、ほかの文字と重なっていない。

### 後片付け
なし。

## PROC-007

### 準備
1. アプリを止めて起動する。
2. 横向きにする: `adb -s emulator-5554 shell settings put system accelerometer_rotation 0`、`adb -s emulator-5554 shell settings put system user_rotation 1`。3秒待つ。

### 操作と確認
1. 画像を残す。確認(人): 入力欄が横に切れておらず、項目名と値が読める。
2. 下へスクロールして `eventProb` を押し、中身を消して 0 を入れる(TD-010 の 横向き)。キーボードを閉じる。確認(人): 入力できて、値が 0 になっている。画像を残す。
3. 下へスクロールして「開始」を押す。確認(人): 「開始」が切れずに見え、押せる。
4. 結果の行が見える位置までスクロールして画像を残す。確認(人): 結果の行の文字が切れたり重なったりせず読める。

### 後片付け
1. 縦向きに戻す: `adb -s emulator-5554 shell settings put system user_rotation 0`、`adb -s emulator-5554 shell settings put system accelerometer_rotation 1`。
