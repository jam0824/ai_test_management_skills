# テストデータ

どのファイルも JSON。入力は「起動し直した直後」から、書いた項目だけを変える(書いていない項目は起動直後の値のまま)。キーは README.md の入力欄の resource-id。金額は円、率は%、年齢は歳の整数で、入力欄にそのまま入れる。

実行時間を短くするため、最後の行まで読むテストの多くは開始年齢を55歳にした(テスト設計で開始年齢を決めていないテストケースだけ。境界から離れた現役の月を55〜58歳に残す)。年収のはしごなど、一部の月だけで判定するテストは、判定に要る月まで読んだら読むのをやめる(`読む範囲`)。

| ID | 内容 | ファイル |
|---|---|---|
| TD-001 | 仕様書の初期値を円・%・歳に直した値(期待値)と、15項目の項目名 | テストデータ/初期値と項目名.json |
| TD-002 | 年収のはしご25段と、各段の年収÷12 | テストデータ/年収のはしご.json |
| TD-003 | 期間を見分けられる入力(P)とその変形、退職 = 年金(E、E0)、退職 > 年金(R70、R66) | テストデータ/期間と年齢の入力.json |
| TD-004 | 最初の残高、開始年齢、投資率・利回りのはしご、12か月比の範囲 | テストデータ/投資と利回り.json |
| TD-005 | 総資産の性質、取り崩し、資金切れ、不足額と投資残高の入力。「現金不足」(HTC-049)は開始時貯金10万円、開始時投資残高2億円、生活費 > 収入(現役30万円・退職後20万円・年金22.8万円)、投資率0%・利回り0%、イベント0% | テストデータ/取り崩しと資金切れ.json |
| TD-006 | 給与変更設定の行の値(1〜5件)と、比べる実行・比べる月 | テストデータ/給与変更.json |
| TD-007 | イベント発生率の入力、出てはならないイベント名、二項分布の範囲 | テストデータ/イベント.json |
| TD-008 | 回転のテストの14項目の値と給与変更2件 | テストデータ/回転と全項目.json |
| TD-009 | 初期値の実行、押し直し、利用の流れの入力 | テストデータ/基本と再実行.json |
| TD-010 | 手動テスト(権限・通信量・機内モード・桁の多い金額・横向き)の値 | テストデータ/手動テスト.json |
| TD-011 | 探索的テストで使える正しくない入力の候補と、仕様書の使用例 ケース1〜4 | テストデータ/探索的テスト.json |
