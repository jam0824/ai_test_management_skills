CH-003: 開始年齢・退職年齢・年金開始年齢の前後関係を崩した組み合わせ(開始 > 退職、開始 > 年金、開始 = 退職 など)で探索し、エラーにならずに誤った結果が出る所を見つける。対象: 年齢の入力欄、開始、結果の表示。ふるまいは Q-011、境目の月は Q-002 の回答待ち。

## 使ったテストデータ

TD-011 の 年齢の前後関係の崩れ: {startAge 70, retirementAge 65}、{startAge 66, retirementAge 65, pensionStartAge 67}、{startAge 65, retirementAge 65}。加えて startAge 100・101、retirementAge 65.5、{startAge 95, retirementAge 150, pensionStartAge 60}。eventProb はすべて 0。証跡は `SES-004/`。

## テストメモ

1. startAge 70 > retirementAge 65(年金65)(s4_1)→ 70歳1月から年金と老後生活費。給与の月は1つも無く、エラーも知らせも無い。前後関係が崩れていることには気づけないが、結果の中身は「70歳の時点で退職済み」と読めば筋は通る → 退職と年金のあいだに開始年齢を置く。
2. startAge 66、retirementAge 65、pensionStartAge 67、gapIncome 50000(s4_2)→ 66歳は退職後収入と退職〜年金開始の生活費、67歳1月から年金。境目は年齢が変わった1月。投資残高が0でも毎年 `== 67歳 1月: 投資利息 ==` と `投資: ¥0 → ¥0` が出る(意味の無い行。記録だけ)→ 開始年齢の上の端を見る。
3. startAge 100(s4_3)→ 100歳1月〜12月の12か月だけ出る。startAge 101 → 結果が0行で、何も知らせない(SES-003 の 200歳と同じ)。→ 有効な結果を出したあとに 101 にしたら前の結果が残るか(残ると、新しい条件の結果と取り違える)。
4. 初期値で開始して結果を出し、startAge を 101 にして開始し直す(s4_5)→ 前の結果は消え、0行になる。古い結果が残って取り違える危険は無い。ただし0行の理由は表示されない → 開始 = 退職 を見る。
5. startAge 65 = retirementAge 65(年金65)(s4_6)→ 65歳1月から年金。開始と同じ年齢で退職すると、現役の月は0か月。筋は通る → 退職年齢の小数を見る。
6. startAge 65、retirementAge 65.5(s4_7)→ 65歳の12か月は給与、66歳1月から年金。退職年齢の小数は年単位で切り上げた扱いになる(65.5歳=65歳7月の退職にはならない)。Q-002・Q-010 の回答で判断する → 退職年齢が100を超えるときを見る。
7. startAge 95、retirementAge 150、pensionStartAge 60(s4_8)→ 100歳12月まで給与と現役時生活費のまま。年金開始年齢を過ぎていても年金は入らない(退職 > 年金。Q-003)。100歳で給与を受け取る結果が、何も知らせずに出る。
8. startAge 62、retirementAge 65、pensionStartAge 60、gapIncome 50000、expenseGap 100000(s4_9)→ 62〜64歳は給与と現役時生活費、65歳1月から年金と老後生活費。退職後収入と退職〜年金開始期間の生活費は、入れても一度も使われず、そのことは知らされない(Q-003)。
9. startAge 64 = retirementAge 64、pensionStartAge 64.5(s4_10)→ 64歳は退職後収入、65歳1月から年金。年金開始の小数も年単位で切り上げた扱い(6 と同じ)。
10. startAge 101、retirementAge 50 で開始(0行)したあと、横向き → 縦向き → 落ちず、入力(101、50)は残った。0行の状態でも回転で入力は失われない。
11. retirementAge 30 = pensionStartAge 30 = 開始年齢(s4_11)→ 30歳1月から年金 ¥145,000 と老後生活費。30歳で年金を受け取る結果が、何も知らせずに出る(Q-011)。

アイデア・リスク:
- 年齢の前後関係が崩れても、どの組み合わせも「年齢 < 退職 なら給与、年齢 < 年金 なら退職後、そうでなければ年金」という順番で一貫して決まり、落ちたり読めない値が出たりはしなかった。問題は、利用者が入力の誤りに気づけないこと。
- 退職 > 年金 のとき年金が入らない(Q-003)のは、使用例ケース4 にも当たる(SES-001)。

## 課題

- 開始年齢が 100 を超えると、開始しても結果が0行で、何も知らせない(Q-001・Q-011)。利用者には、押せていないのか結果が無いのか分からない。

- 投資残高が0でも毎年「投資利息」の行が出る(表示の仕様。Q-021)。
