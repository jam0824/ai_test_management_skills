## BUG-001

- 再現できる手順:
  1. アプリを起動し直す。
  2. startAge 55、retirementAge 60、pensionStartAge 65、gapIncome 0、expenseCurrent 150000、expenseGap 200000、eventProb 0、interest 0、investRate 0、initialInv 212500 を入れる(TD-005 不足額と投資残高 の D + 100000)。
  3. 「開始」を押し、現金が足りなくなる月(61歳5月ごろ)まで結果を読む。
- 期待値: 利回り0%で、収入と生活費以外の出入りが無い月は、総資産の増減 = 収入 − 生活費(仕様書「現金不足時の投資資産取り崩し機能」。取り崩しで資産が余分に減ることは仕様書に書かれていない)。
- 実際の結果: 補填した月に `🔄 投資から補填: ¥X (税金: ¥0.2X)` が出て、投資から X + 0.2X が引かれる。総資産は収入 − 生活費より 0.2X 多く減る。例(LTC-036、TD-005 総資産の増減): 60歳7月 総資産 22,387,500 → 22,233,500(−154,000)。収入 50,000 − 生活費 200,000 = −150,000 なので 4,000(補填額 20,000 の20%)余分に減った。LTC-036 では判定した246行のうち181行がこのずれ。
- 影響: 現金が足りなくなる月があるすべての条件で、総資産・投資残高が仕様書から読める値より少なく出る。投資率を上げると現役中に毎月補填が起き、そのたびに20%減るので、投資率50%・100%のほうが投資率20%より投資残高が少なくなる(LTC-034、61歳4月 投資率50% 3,257,574 < 投資率20% 3,265,080)。
- 証跡: RUN-20261123-104110/証跡/LTC-036_5_run1_総資産の増減_lines.txt(275〜279行目)、LTC-036_6_判定.txt、LTC-038_8_run2_D_100000_lines.txt、LTC-038_15_判定.txt、LTC-034_11_run3_投資率50_lines.txt(372〜376行目)、LTC-034_15_判定.txt
- 補足: 取り崩しに税金をかけるのが意図した仕様かどうかは、仕様書に無い(Q-013 は取り崩しの基準を聞いているが未回答)。意図した仕様なら、仕様書への記載漏れになる。テスト対象のソース(Simulator.kt の投資補填)でも、補填額の20%を「税金」として投資から引いていることを確かめた(期待値はソースから決めていない)。
- 質問: 取り崩しに税金をかけるのが仕様かを Q-028 で聞いている。Q-028 の回答で、不具合かどうかが変わる(仕様なら却下になりうる)。

## BUG-002

- 再現できる手順:
  1. アプリを起動し直す。
  2. BUG-001 と同じ入力で、initialInv を 112500(TD-005 の D)にして「開始」を押す。
  3. 61歳5月の行を見る。
- 期待値: 投資資産の取り崩しは、残っている投資資産の範囲で行われ、投資残高は0円未満にならない(仕様書「現金不足時の投資資産取り崩し機能」)。
- 実際の結果: `🔄 投資から補填: ¥112,500 (税金: ¥22,500)` のあと `現金: ¥0 投資: ¥-22,500 総資産: ¥-22,500`。投資残高がマイナスになる。マイナスの投資残高には年初に利回りが掛かり、利回りが高いほどマイナスが大きくなる(LTC-033: 75歳8月 利回り10% の投資 −12,098 < 利回り4% の投資 −5,197。69歳6月 利回り1% −9,926 < 利回り0% −120)。
- 影響: 資金が尽きる条件で、投資残高に意味の無いマイナスの値が出る。利回りを上げると資産が減って見える。
- 証跡: RUN-20261123-104110/証跡/LTC-038_11_run3_D_lines.txt(316〜321行目)、LTC-033_18_判定.txt、LTC-033_14_run4_利回り10_lines.txt
- 補足: 原因は BUG-001 の税金(投資残高と同じ額を取り崩したうえに、その20%を投資からさらに引く)と同じ処理にある。BUG-001 を直すときに一緒に直る見込みだが、税金を残す仕様にした場合もマイナスにならないようにする必要があるので、分けて書いた。

  1. アプリを起動し直し、「📈 給与変更設定を表示/非表示」を押す。
  2. 「➕ 給与変更を追加」を3回押し、上から (35, 4000000)、(40, 5000000)、(45, 6000000) を入れる(TD-006 の 3件)。

- 証跡: RUN-20261123-104110/セッションシート/SES-002/s2_7_minusInfinity.png、s2_7_logcat.txt(`ANR in jp.sample.retirementsimulator`)、SES-003/s3_4_開始マイナス100万.png、s3_4_logcat.txt
