# テスト分析

入力: `03_テスト計画/テスト計画.md`(TA-001〜018)、`01_要求仕様/要求.md`・`仕様.md`、`02_リスク分析/リスク分析.md`、各工程の `レビュー結果.md` の申し送り、`質問表.md`(Q-001〜Q-027 はすべて未回答)。テストベースは `仕様書.md` と `README.md`。

テスト計画の方針どおり、1円単位の値と境界の月の期待結果は回答待ち(質問のIDを備考に書く)にし、テストベースから決まる性質(初期値、0%・100%などの極端値、総資産 = 現金 + 投資、単調性、期間による使い分け、落ちない・NaN を出さない)はテスト条件として決めている。

性質で確かめるテスト条件の多くは、次の前提に立つ。前提が崩れる回答が来たら、該当するテスト条件を見直す。

- **表示される給与収入は手取り**(Q-021 の回答待ち)。COND-022、024、025、029、035 はこの前提で判定する。とくに COND-022 は、額面で表示される実装なら「年収÷12 より小さい」が Fail になる。額面表示が正しいと回答されたら、この性質では手取りを確かめられないので、テスト条件ごと見直す。
- **現金には利回りが付かない**(仕様書で利回りは「投資の年利回り」とだけ書かれているため)。
- イベント以外の計算を確かめるテスト条件は、イベント発生率0%で行う(テスト計画の制約。0%でイベントが起きないことは COND-052 で確かめる)。
